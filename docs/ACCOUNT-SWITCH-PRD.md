# 多账号快速切换 PRD

> 状态：1.8.0 实现。文档先于开发，下面的「验收标准」就是测试用例的来源。

## 1. 背景与目标

现在换账号 / 换禅道要重新输入「地址 + 账号 + 密码」，而且输入完还会碰上一道「清空本地数据」的确认。真实使用里这类切换并不少见：

| 谁 | 为什么要切换 | 频率 |
|---|---|---|
| 同时有新旧两套禅道的人（正在迁移期，如 18.x ↔ 22.x） | 旧的看历史、新的做事 | 每天几次 |
| 有多个账号的人（自己的 + 管理员 / 代管的项目账号） | 不同账号权限不同 | 每周几次 |
| 测试 / 演示 | 正式环境和测试环境来回切 | 开发期很高 |

**目标：** 登录过的账号（地址 + 账号 + 密码）自动记住，从头像菜单**一步**切换；切换中数据不丢、不会串、失败时知道怎么办。

**不是目标：** 同时登录多个账号并行显示；多个账号各自保留一份本地数据（见 §7 后续）。

## 2. 设计原则

1. **一步到位**：已保存的账号，点一下就切，不再输入任何东西。
2. **默认记住，无需勾选**：每次登录成功自动保存；想忘掉的，在列表里明确移除。多一个「记住密码」勾选框只会让人漏勾。
3. **数据安全第一**：禅道才是数据的唯一来源，本地数据切换时重新同步即可；但切换前一定先备份，且**只有本地存在「还没同步到禅道的内容」时才打断用户确认**——绝大多数切换（本地内容都来自禅道）是零确认的。
4. **失败要可恢复**：保存的密码失效、连不上、账号被禁用，各有明确的下一步，不会把用户留在半切换的状态。
5. **密码不外露**：只存在本机的数据目录，界面和接口永远不回传密码。

## 3. 范围

**做：**
- 登录成功自动保存账号（按「地址 + 账号」唯一，重复登录更新密码和最近使用时间）。
- 头像菜单里列出其他已保存账号，点击即切换；每行可移除。
- 登录卡片（未登录 / 退出后 / 添加账号）顶部同样列出已保存账号，可点击快速登录。
- 切换前备份 `tasks.json`；只在有未同步的本地内容时确认。
- 老用户升级后，当前正在用的账号自动进入列表（不用重新登录一遍）。

**不做（本期）：** 本地数据按账号分别保留 / 恢复；账号分组、重命名、排序拖拽；跨设备同步账号；密码加密存储（见 §6）。

## 4. 交互设计

### 4.1 头像菜单

```
┌──────────────────────────────┐
│ [李] 李佳成                  │
│      lijc · 研发              │
│ ● 已连接 · 刚刚同步           │
│ 禅道  http://192.168.2.42:8088 │
├──────────────────────────────┤
│ 切换账号                      │
│ [张] 张三                  ×  │   ← 点整行 = 切换；× = 移除
│      zhangs · 10.128.1.8 · 18.3│
│ [李] 李佳成                ×  │
│      lijc · 10.128.1.8 · 18.3 │
├──────────────────────────────┤
│ ⚙ 设置                        │
│ ＋ 添加账号                   │
│ ⏻ 退出登录                    │
└──────────────────────────────┘
```

- 其他账号按**最近使用**排序，当前账号不在列表里（头部已经是它）。
- 每行：头像色块 + 姓名 + `账号 · 禅道主机 · 禅道版本`。版本很有用：新旧两套禅道账号名常常一样，靠它一眼区分。
- 超过 5 个时列表可滚动，不撑破菜单。
- 没有其他账号时不显示「切换账号」分组，只有「添加账号」。

### 4.2 登录卡片

「添加账号 / 登录禅道 / 退出后再登录」的卡片，在表单上方加「已保存的账号」：每行同样可点击直接登录，点击后不需要再输密码。只剩一个账号且就是刚退出的那个时，也一样显示——退出后一键回去。

已登录时，列表里**当前账号也会显示**（标「当前」，不能点），这样「切换账号」页面里总能看到有哪些账号；只有当前账号时给一句说明「登录过的账号会自动保存在这里」，不留空白。

**换下来的账号也要记住**：换账号 / 换地址前（登录弹窗、设置保存、配置导入三个入口），先把当前账号和密码存进列表——密码这时还在配置里，换掉就找不回来了。

「密码已失效」的重新登录（relogin）卡片不显示列表，只输密码。

### 4.3 切换流程

```
点击账号
  │
  ├─ 后端用保存的密码真实登录一次 ──失败──┐
  │                                      │ 密码错误 → 打开「重新输入密码」卡片（地址、账号已填好，提示「保存的密码已失效」）
  │                                      │ 连不上   → 提示「连不上 xxx，检查网络 / VPN」，保持当前账号不变
  │                                      │ 其他     → 显示禅道返回的原因
  ├─ 成功，且本地有「未同步到禅道」的内容 ─→ 确认框：「有 N 条只存在本机的任务 / Bug，切换会清空（已备份）」
  │                                      取消 → 保持当前账号，什么都没改
  ├─ 备份 tasks.json → 清空本地数据 → 切换配置
  └─ 显示进度（同步执行 / 团队 / 我的任务与 Bug）→ 刷新页面
```

关键点：**先验证再动手**。密码错、连不上这两种最常见的失败，在清任何数据之前就已经被拦下，用户当前的状态完全不受影响。

### 4.4 其他入口的行为

- **退出登录**：只清当前密码与会话，保留账号列表（下次从列表一键回来）。
- **移除账号**：从列表删除（连同保存的密码）。不能移除正在使用的账号——提示「请先切换到别的账号」。
- **设置 → 切换账号按钮**：打开登录卡片（含已保存列表），行为同 §4.2。
- **设置里直接改禅道地址 / 账号**：沿用 1.7.1 的逻辑（备份并清空旧数据），改完也会进入列表。

## 5. 接口

| 接口 | 说明 |
|---|---|
| `GET /api/account/saved` | 已保存账号：`id, url, username, realname, roleLabel, version, lastUsedAt, current`。**不含密码** |
| `POST /api/account/switch` `{id, confirmSwitch?}` | 用保存的凭据切换。需确认时返回 `needConfirm` + `unsynced`（未同步条数）；密码失效返回 `error.kind=credentials` |
| `DELETE /api/account/saved/:id` | 移除；当前账号返回 409 |
| `POST /api/account/login` | 成功后自动保存 / 更新（原有接口） |

`id` = 「规整后的地址 + 账号」的哈希，同一个账号同一个地址只会有一条。

## 6. 数据与安全

- 存放：`data/accounts.json`，权限 0600，与现有 `.env`（同样保存禅道明文密码）处于同一安全级别：只有本机当前用户能读。
- 接口和界面永远不返回密码；日志不打印密码。
- 上限 10 个，满了淘汰「最近最少使用」且不是当前的那个。
- 为什么不加密：加密需要密钥，密钥只能放在同一台机器上，防不住能读这个目录的人，却会让「忘记 / 换机」的排查更麻烦。真要防，应该用系统钥匙串，列入后续。

## 7. 后续（本期不做）

- 本地数据按账号分别保留，切回来不用重新同步。
- 用系统钥匙串（macOS Keychain / Windows 凭据管理器）存密码。
- 账号别名（「正式 / 测试」），按别名显示。

## 8. 验收标准

1. 登录成功后，该账号出现在 `GET /api/account/saved`，且响应里没有 `password` 字段。
2. 同一地址同一账号重复登录只有一条，密码和最近使用时间被更新。
3. 地址大小写、末尾斜杠、`/zentao/...` 后缀不同视为同一个账号。
4. 升级后（有 `.env` 凭据但没有 `accounts.json`）当前账号自动进入列表。
5. `switch` 目标密码错误：返回 credentials，**本地数据和当前配置都不变**。
6. `switch` 目标连不上：返回 offline，**本地数据和当前配置都不变**。
7. `switch` 时本地所有任务 / Bug 都已同步（有禅道编号）：不需要确认，直接切换并清空，`tasks.json` 已备份。
8. 本地有未同步的任务 / Bug：返回 `needConfirm` 和条数，不改任何东西；`confirmSwitch=true` 后才切换。
9. 不能移除当前账号（409）；可以移除其他账号，移除后列表和文件里都没有。
10. 退出登录后列表仍在；退出状态下点已保存账号可直接登录。
11. 头像菜单：其他账号按最近使用排序，显示姓名、账号、主机、版本；点击发起切换；× 移除（需确认）；没有其他账号时没有「切换账号」分组。
12. 登录卡片顶部显示已保存账号，点击即切换；relogin 模式不显示。
13. 切换成功后显示同步进度并刷新；失败时按 §4.3 的分支提示。
