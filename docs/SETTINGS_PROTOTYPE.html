设置页原型：一个界面，管完所有配置

这是 完整界面设计方案 中「原型 · 设置面板」的完整交互版：左侧 7 个分组一键直达，本地服务置顶，显式保存 + 脏状态提示，危险操作二次确认。原型内的数据均为演示数据，所有交互可真实操作。

切换分组（支持 ↑ ↓ 键） 改任意字段 → 底部出现未保存计数 连点两次「重置默认」才会执行 本地服务：重启 / 停止 / 启动状态机 「调试模式」收起所有测试按钮 右上角切换墨台 / 夜台 / 窄屏

设置页设计决策

旧版设置是一个 800px 弹窗里五个 section 纵向罗列，找回一项设置要整屏滚动，测试按钮与调试开关散落各处。这一版按「使用频率 × 风险等级」重组信息架构。

本地服务置顶且说人话

它是所有功能的地基，也是出问题时的第一现场。PID / 端口 / 来源 / 开机自启四格等宽字体呈现，「来源: 插件启动」直接回答「谁拉起的」这个高频疑问。

分组导航替代无限滚动

七个分组一键直达，当前项用白底 + 阴影标示。导航支持 ↑↓ 键，符合 WAI-ARIA 选项卡模式预期。窄屏时自动收成顶部横向 tabs。

显式保存 + 脏状态提示

改任何字段，底部立刻出现「有 N 项未保存的修改」，鼠标悬停可看到具体改了哪些项；保存按钮仅在真有改动时可点，避免「以为自动保存了」的误解。

危险操作二次确认

「重置默认」第一次点击变为「确认重置？」并进入警告态，3 秒内不确认自动收起了，防止手滑丢配置。停止服务、停用开机自启同样属于需确认的动作。

提示词并入设置

旧版提示词是另一个弹窗，用户要记两个入口、两套保存按钮。现在作为设置的一个分组，一个界面管完所有配置，保存模型也统一。

密钥只进本机 .env

API Key 与禅道密码旁固定显示「仅保存在本机 .env，不同步、不上传」——把用户最大的顾虑直接在字段旁回答掉，而不是藏进文档。

调试模式收纳测试按钮

测试连接、查看日志等开发期能力收进标题栏的「调试模式」开关，普通用户默认看不到。本原型默认开启，方便评审完整体验。

暗色是一等公民

夜台主题不是把墨台反色：用表面明度递进（#1A1815 → #23201C → #2C2924）表达层级，强调色换为高对比的 #5EEAD4，控件与文字对比度全部通过 WCAG AA。
